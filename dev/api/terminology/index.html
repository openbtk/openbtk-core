    Terminology¶

    Terminology resolution is licence-aware: no restricted vocabulary is bundled.

    openbtk.terminology.cache.CachedTerminologyService ¶

    CachedTerminologyService(*, backend: BaseTerminologyService, cache_dir: str, ttl_seconds: float = 86400.0)

    Bases: BaseTerminologyService

    Wrap backend with a TTL disk cache under cache_dir.

    Parameters:

    Name Type Description Default
    backend BaseTerminologyService

    The real terminology service to cache results from.

    		 required
    cache_dir str

    Directory for cache files. Created lazily on first real write, not in __init__ (docs/09_CODING_STANDARDS.md rule 11).

    		 required
    ttl_seconds float

    How long a cached entry stays valid. Default one day.

    		 86400.0
    Example

    import tempfile from openbtk.terminology.bundled import BundledMinimalBackend with tempfile.TemporaryDirectory() as d: ... cached = CachedTerminologyService( ... backend=BundledMinimalBackend(), cache_dir=d, ... ) ... first = cached.resolve("E11.9", CodeSystem.ICD10CM) ... second = cached.resolve("E11.9", CodeSystem.ICD10CM) first == second True
